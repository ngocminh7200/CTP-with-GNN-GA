# Graph-Guided Scheduling: A GNN-Genetic Algorithm Hybrid for College Timetabling Optimization

## Abstract

The Curriculum-Based College Timetabling Problem (CB-CTP) is a well-known NP-hard combinatorial optimisation problem arising in university scheduling. This study proposes a hybrid framework that integrates a supervised heterogeneous Graph Neural Network (GNN) within a Genetic Algorithm (GA) as a learned improvement operator. The GNN is trained using a pseudo-curriculum learning strategy on progressively larger synthetic instances solved by Gurobi, allowing it to capture constraint-aware structural patterns from timetable solutions. The problem is represented as a heterogeneous graph consisting of courses, staff, rooms, programs, and timeslots, where attention-based message passing is used to refine timetable assignments. Experiments on an LSE Autumn-term instance show that the proposed GA-GNN framework achieves a decent improvement compared to a vanilla GA, primarily through reducing hard-constraint violations. Additional scaling experiments on synthetic instances ranging from 50 to 800 courses demonstrate that the benefit of the GNN increases with problem complexity. Furthermore, GA-GNN exhibits substantially faster convergence, reaching the final fitness level of the vanilla GA in approximately one-third of the generations. These findings suggest that graph-learned repair operators provide a scalable alternative to manually designed heuristics for educational timetabling problems.
